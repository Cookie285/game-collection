# Game collection — notes for Claude

Physical game collection tracker: CLZ Games CSV → `data/collection.csv` → Markdown views + a static web app (GitHub
Pages). Everything is generated by `scripts/gamecoll.py` (Python 3.11+, no dependencies).

- **New CLZ export or "what changed?"** → follow the `collection-review` skill (`.claude/skills/collection-review/SKILL.md`).
- Curated data: `data/targets/*.toml` (buy plan), `data/series/*.toml`, `data/rules.toml` (rules + platform strategy),
  `data/decisions.toml` (open questions + decision log), `data/annotations.csv`. Generated — never hand-edit:
  `data/collection.csv`, `views/`, `OPEN-QUESTIONS.md`, the README summary block, `site/data.json`.
- After editing data: `python3 scripts/gamecoll.py check` then `render`; before a PR also
  `python3 -m unittest discover -s tests && node tests/engine.test.js` (CI runs the same); `export` + `python3 -m http.server -d site`
  to preview the web app.
- The repo is public: no prices, stores, addresses or personal data unless the user asks.
- Don't make collecting decisions for the user — record facts, options and recommendations; the user decides.
